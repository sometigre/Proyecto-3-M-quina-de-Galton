# Simulación de Máquina de Galton en Python

Este proyecto simula la caída de canicas en una máquina de Galton utilizando estructuras básicas de Python.

## structura

- `main.py`: archivo principal
- `galton.py`: contiene la lógica de la simulación
- `plot.py`: genera un histograma
- `requirements.txt`: dependencias

## Uso

```bash
python main.py
